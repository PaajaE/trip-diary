# Architecture

## Boundaries

```text
UI -> application services -> repositories -> IndexedDB / Supabase
```

- UI components do not call Supabase directly.
- Untrusted external data is validated at the boundary with Zod.
- Database types are generated by Supabase CLI and never edited manually.
- Domain types are mapped explicitly instead of exposing database rows to UI.
- Offline domain writes will go through the local repository and sync queue.

## Type safety

- TypeScript runs in strict mode with unchecked indexes and exact optional properties.
- `any`, non-null assertions, floating promises, and non-exhaustive switches fail lint.
- PostgreSQL constraints and RLS remain authoritative for server-side invariants.

## Design

- Mobile-first, with one clear primary action per screen.
- Photos and content take visual priority over controls.
- Tokens remain small and semantic: background, surface, foreground, muted, border,
  primary, accent, and destructive.
